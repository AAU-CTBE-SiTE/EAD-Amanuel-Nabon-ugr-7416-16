# Enterprise Application Development - JDBC Lab

**Author:** Nabon Amanuel Tefera (ugr-7416-16)

## Overview
This repository contains the completed Java Database Connectivity (JDBC) lab assignment for the Enterprise Application Development course. The project demonstrates how to connect a Java application to a MySQL database and perform basic CRUD (Create, Read, Update, Delete) operations using the `java.sql` API.

## Tasks Completed
This code successfully executes the 6 practice tasks outlined in the lab manual:
1. **Database Setup:** Connects to the local MySQL server and creates the `StudentsDB` database and `students` table.
2. **Insert Data:** Inserts an initial student record, followed by a batch insert of 10 additional student records.
3. **Retrieve Data:** Fetches and prints the first 5 student records.
4. **Update Data:** Modifies the database by updating the first name of the student with ID 1.
5. **Delete Data:** Removes the student record with ID 2 from the table.
6. **Calculate Average:** Computes and prints the average grade of all students in the database.

## Prerequisites
* **Java Development Kit (JDK):** Installed and configured.
* **IDE:** Apache NetBeans.
* **Database:** MySQL Server running locally on port `3306`.
* **Driver:** [MySQL Connector/J](https://dev.mysql.com/downloads/connector/j/) `.jar` file.
